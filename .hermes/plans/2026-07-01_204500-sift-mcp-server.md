# Sift MCP Server Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add an MCP (Model Context Protocol) server to Sift that exposes key RSS/article/feed operations as MCP tools, supporting both local stdio (for Hermes on the dev machine) and remote StreamableHTTP over TLS (for VPS deployment).

**Architecture:** The MCP server is integrated into the Sift FastAPI application — not a separate process. It calls service-layer functions directly (same as REST routes), sharing DB sessions, config, and auth. For local use, a `sift-mcp` stdio entry point is provided. For VPS deployment, a `/mcp` StreamableHTTP endpoint is mounted on the FastAPI app, authenticated via API tokens (the `ApiToken` model already exists in the DB but has no routes — this plan implements token CRUD + validation as a prerequisite).

**Tech Stack:** Python 3.13, FastAPI, `mcp` Python SDK, SQLAlchemy async, Pydantic, uv, pytest

**Decisions captured:**
- MCP server is integrated into the FastAPI app (shared services, single deployable), not a separate HTTP-proxy process
- Two transports: stdio (local `sift-mcp` CLI) + StreamableHTTP (`/mcp` route on the app)
- Auth: API token (bearer token in `Authorization` header for HTTP; `SIFT_MCP_TOKEN` env var for stdio)
- The existing `ApiToken` model (`src/sift/db/models.py:159`) is used — token CRUD routes + middleware validation are implemented first
- MCP tools call service-layer functions directly (e.g. `article_service.list_articles()`), not HTTP — zero network overhead
- Tool set is read-heavy initially: list feeds, list/search articles, get article detail, list folders, navigation tree, feed health. Write tools (add feed, OPML import, mark read) are included but secondary
- `mcp` SDK added as a core dependency in `pyproject.toml` (not optional) — MCP is a first-class Sift feature

**Assumptions:**
- `ApiToken` model exists at `src/sift/db/models.py:159-169` with `token_hash`, `scopes_json`, `expires_at`, `last_used_at`, `revoked_at` — but no API routes create or validate tokens
- Auth is currently cookie-based only (`src/sift/api/deps/auth.py:11-27` — `get_current_user` reads `request.cookies`)
- All API routes use `get_current_user` dependency for auth
- Service layer is async: `article_service`, `feed_service`, `folder_service`, `navigation_service`, `feed_health_service`, `opml_service`, `stream_service`, `search_provider_service` — all take `session: AsyncSession` + `user_id: uuid.UUID`
- FastAPI app is created in `src/sift/main.py:42` (`app = FastAPI(...)`)
- Dev container runs FastAPI at `http://sift.localhost` via Traefik (`docker-compose.yml:56-59`)
- Production deployment will use the same FastAPI app behind a TLS-terminating reverse proxy (Traefik/Caddy) — MCP endpoint inherits the same TLS
- `mcp` SDK supports both `stdio` and `streamable_http` transports (confirmed in Hermes native-mcp reference)

- Frontend: not affected by this plan
- Docker: `Dockerfile` builds `sift-portal` with `uv sync --extra dev`

### Step 3: Implement token service

**File:** `src/sift/services/token_service.py`

```python
import hashlib
import secrets
from datetime import datetime
from uuid import UUID

from sqlalchemy import select, update
from sqlalchemy.ext.asyncio import AsyncSession

from sift.db.models import ApiToken, User

TOKEN_PREFIX = "sft_"
TOKEN_BYTES = 32


class TokenError(Exception):
    pass


class TokenNotFoundError(TokenError):
    pass


def _hash_token(raw: str) -> str:
    return hashlib.sha256(raw.encode()).hexdigest()


def _generate_raw_token() -> str:
    return TOKEN_PREFIX + secrets.token_hex(TOKEN_BYTES)


class TokenService:
    async def create_token(
        self,
        session: AsyncSession,
        user_id: UUID,
        name: str,
        scopes: list[str] | None = None,
        expires_at: datetime | None = None,
    ) -> tuple[str, ApiToken]:
        raw = _generate_raw_token()
        token = ApiToken(
            user_id=user_id,
            name=name,
            token_hash=_hash_token(raw),
            scopes_json=secrets.token_hex(0),  # placeholder, overwritten below
            expires_at=expires_at,
        )
        import json
        token.scopes_json = json.dumps(scopes or [])
        session.add(token)
        await session.commit()
        await session.refresh(token)
        return raw, token

    async def validate_token(self, session: AsyncSession, raw_token: str) -> ApiToken | None:
        if not raw_token.startswith(TOKEN_PREFIX):
            return None
        token_hash = _hash_token(raw_token)
        stmt = select(ApiToken).where(
            ApiToken.token_hash == token_hash,
            ApiToken.revoked_at.is_(None),
        )
        result = await session.execute(stmt)
        token = result.scalar_one_or_none()
        if token is None:
            return None
        if token.expires_at is not None and token.expires_at < datetime.now(token.expires_at.tzinfo):
            return None
        # Update last_used_at
        await session.execute(
            update(ApiToken).where(ApiToken.id == token.id).values(last_used_at=datetime.now(token.expires_at.tzinfo if token.expires_at else None))
        )
        await session.commit()
        return token

    async def list_tokens(self, session: AsyncSession, user_id: UUID) -> list[ApiToken]:
        stmt = select(ApiToken).where(
            ApiToken.user_id == user_id,
            ApiToken.revoked_at.is_(None),
        ).order_by(ApiToken.created_at.desc())
        result = await session.execute(stmt)
        return list(result.scalars().all())

    async def revoke_token(self, session: AsyncSession, user_id: UUID, token_id: UUID) -> None:
        stmt = select(ApiToken).where(
            ApiToken.id == token_id,
            ApiToken.user_id == user_id,
            ApiToken.revoked_at.is_(None),
        )
        result = await session.execute(stmt)
        token = result.scalar_one_or_none()
        if token is None:
            raise TokenNotFoundError("Token not found or already revoked")
        token.revoked_at = datetime.now(token.expires_at.tzinfo if token.expires_at else None) if token.expires_at else datetime.now()
        await session.commit()


token_service = TokenService()
```

```python
from uuid import UUID

from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession

from sift.api.deps.auth import get_current_user
from sift.db.models import User
from sift.db.session import get_db_session
from sift.domain.schemas import ApiTokenCreate, ApiTokenCreatedOut, ApiTokenOut, ApiTokenRevokeOut
from sift.services.token_service import TokenNotFoundError, token_service

router = APIRouter()


@router.post("", response_model=ApiTokenCreatedOut, status_code=status.HTTP_201_CREATED)
async def create_token(
    payload: ApiTokenCreate,
    session: AsyncSession = Depends(get_db_session),
    current_user: User = Depends(get_current_user),
) -> ApiTokenCreatedOut:
    raw_token, record = await token_service.create_token(
        session=session,
        user_id=current_user.id,
        name=payload.name,
        scopes=payload.scopes,
        expires_at=payload.expires_at,
    )
    import json
    return ApiTokenCreatedOut(
        id=record.id,
        name=record.name,
        scopes=json.loads(record.scopes_json),
        expires_at=record.expires_at,
        last_used_at=record.last_used_at,
        created_at=record.created_at,
        raw_token=raw_token,
    )


@router.get("", response_model=list[ApiTokenOut])
async def list_tokens(
    session: AsyncSession = Depends(get_db_session),
    current_user: User = Depends(get_current_user),
) -> list[ApiTokenOut]:
    tokens = await token_service.list_tokens(session=session, user_id=current_user.id)
    return [ApiTokenOut.model_validate(t) for t in tokens]


@router.delete("/{token_id}", response_model=ApiTokenRevokeOut)
async def revoke_token(
    token_id: UUID,
    session: AsyncSession = Depends(get_db_session),
    current_user: User = Depends(get_current_user),
) -> ApiTokenRevokeOut:
    try:
        await token_service.revoke_token(session=session, user_id=current_user.id, token_id=token_id)
    except TokenNotFoundError as exc:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail=str(exc)) from exc
    return ApiTokenRevokeOut(revoked=True)
```

```python
from sift.services.token_service import token_service


async def get_current_user_from_token(
    request: Request,
    session: AsyncSession = Depends(get_db_session),
) -> User:
    auth_header = request.headers.get("Authorization", "")
    if not auth_header.startswith("Bearer "):
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Bearer token required")
    raw_token = auth_header[7:]
    token = await token_service.validate_token(session, raw_token)
    if token is None:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid or expired token")

    # Load user
    from sqlalchemy import select
    stmt = select(User).where(User.id == token.user_id)
    result = await session.execute(stmt)
    user = result.scalar_one_or_none()
    if user is None:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Token user not found")
    return user


async def get_current_user_flexible(
    request: Request,
    session: AsyncSession = Depends(get_db_session),
) -> User:
    """Try cookie auth first, fall back to bearer token."""
    settings = get_settings()
    raw_cookie = request.cookies.get(settings.auth_session_cookie_name)
    if raw_cookie:
        try:
            user = await auth_service.get_user_by_session_token(session, raw_token=raw_cookie)
            if user is not None:
                return user
        except SQLAlchemyError:
            pass

    # Fall back to bearer token
    auth_header = request.headers.get("Authorization", "")
    if auth_header.startswith("Bearer "):
        raw_token = auth_header[7:]
        token = await token_service.validate_token(session, raw_token)
        if token is not None:
            from sqlalchemy import select
            stmt = select(User).where(User.id == token.user_id)
            result = await session.execute(stmt)
            user = result.scalar_one_or_none()
            if user is not None:
                return user

    raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Authentication required")
```

```python
                q=arguments.get("q"),
                limit=arguments.get("limit", 100),
                offset=arguments.get("offset", 0),
                sort=arguments.get("sort", "newest"),
            )
            return result.model_dump_json()

        elif name == "sift_get_article":
            from uuid import UUID as UU
            from sift.services.article_service import ArticleNotFoundError
            try:
                detail = await article_service.get_article_detail(
                    session=session, user_id=user_id,
                    article_id=UU(arguments["article_id"]),
                )
                return detail.model_dump_json()
            except ArticleNotFoundError as exc:
                return json.dumps({"error": str(exc)})

        elif name == "sift_list_folders":
            folders = await folder_service.list_folders(session=session, user_id=user_id)
            return json.dumps([{
                "id": str(f.id), "name": f.name, "sort_order": f.sort_order,
            } for f in folders])

        elif name == "sift_get_navigation":
            tree = await navigation_service.get_navigation_tree(session=session, user_id=user_id)
            return tree.model_dump_json()

        elif name == "sift_get_feed_health":
            from typing import Literal
            result = await feed_health_service.list_feed_health(
                session=session, user_id=user_id,
                lifecycle=arguments.get("lifecycle", "all"),  # type: ignore[arg-type]
                q=None, stale_only=arguments.get("stale_only", False),
                error_only=arguments.get("error_only", False),
                include_all=False,
                limit=arguments.get("limit", 50),
                offset=0,
            )
            return result.model_dump_json()

        elif name == "sift_list_streams":
            streams = await stream_service.list_streams(session=session, user_id=user_id)
            return json.dumps([stream_service.to_out(s).model_dump() for s in streams])

        elif name == "sift_add_feed":
            from sift.domain.schemas import FeedCreate
            from pydantic import HttpUrl
            from sift.services.feed_service import FeedAlreadyExistsError, FeedFolderNotFoundError
            try:
                feed = await feed_service.create_feed(
                    session=session, user_id=user_id,
                    data=FeedCreate(
                        title=arguments["title"],
                        url=HttpUrl(arguments["url"]),
                        folder_id=UU(arguments["folder_id"]) if arguments.get("folder_id") else None,
                    ),
                )
                return json.dumps({"id": str(feed.id), "title": feed.title, "url": feed.url})
            except FeedAlreadyExistsError as exc:
                return json.dumps({"error": str(exc)})
            except FeedFolderNotFoundError as exc:
                return json.dumps({"error": str(exc)})

        elif name == "sift_mark_articles_read":
            from uuid import UUID as UU
            ids = [UU(aid) for aid in arguments["article_ids"]]
            count = await article_service.bulk_patch_state(
                session=session, user_id=user_id,
                article_ids=ids, is_read=True,
            )
            return json.dumps({"updated_count": count})

        else:
            return json.dumps({"error": f"Unknown tool: {name}"})
```

```python
"""StreamableHTTP MCP server integrated into FastAPI.

Mounts at /mcp and authenticates via Bearer API token.
"""
import json
from typing import Any

from mcp.server import Server
from mcp.server.streamable_http import StreamableHTTPServerTransport
from mcp.types import TextContent, Tool

from sift.mcp.tools import TOOL_DEFINITIONS, execute_tool

# Create the MCP server instance
mcp_server = Server("sift")


@mcp_server.list_tools()
async def list_tools() -> list[Tool]:
    return TOOL_DEFINITIONS


@mcp_server.call_tool()
async def call_tool(name: str, arguments: dict[str, Any]) -> list[TextContent]:
    # user_id is injected via the session state set by the FastAPI handler
    # (see create_mcp_app_handler below)
    # We use a context variable to pass user_id from the HTTP handler
    from contextvars import ContextVar
    user_id_var: ContextVar = _user_id_var  # type: ignore[name-defined]

    user_id = user_id_var.get()
    if user_id is None:
        return [TextContent(type="text", text=json.dumps({"error": "Not authenticated"}))]

    result = await execute_tool(name, arguments, user_id)
    return [TextContent(type="text", text=result)]


# Context variable for passing user_id from HTTP handler to MCP tool handler
from contextvars import ContextVar
_user_id_var: ContextVar[Any] = ContextVar("mcp_user_id", default=None)


def set_mcp_user_id(user_id: Any) -> None:
    _user_id_var.set(user_id)
```

> **Design note:** MCP's `call_tool` handler doesn't receive request context directly. We use a `ContextVar` to pass the authenticated `user_id` from the FastAPI HTTP handler into the MCP tool execution. This is safe because each MCP session runs in its own async context.

### Step 2: Mount on FastAPI app

**File:** `src/sift/main.py` — add after `app.include_router(api_router)` (line 50):

```python
# MCP StreamableHTTP endpoint
from mcp.server.streamable_http import StreamableHTTPServerTransport
from starlette.requests import Request
from starlette.responses import Response
from sift.mcp.server import mcp_server, set_mcp_user_id
from sift.api.deps.auth import get_current_user_flexible
from sift.db.session import get_db_session
from sift.db.models import User


@app.post("/mcp")
@app.get("/mcp")
async def mcp_endpoint(request: Request) -> Response:
    """StreamableHTTP MCP endpoint.

    Auth: cookie session OR Bearer API token (via get_current_user_flexible).
    """
    # Authenticate
    session = await anext(get_db_session())
    try:
        user: User = await get_current_user_flexible(request, session)
    except Exception:
        from fastapi.responses import JSONResponse
        return JSONResponse(status_code=401, content={"detail": "Authentication required"})

    set_mcp_user_id(user.id)

    # Handle MCP StreamableHTTP
    transport = StreamableHTTPServerTransport(
        mcp_session_id=None,  # stateless mode
    )

    async with transport.run() as (read_stream, write_stream):
        await mcp_server.run(
            read_stream, write_stream,
            mcp_server.create_initialization_options(),
        )

    return Response(status_code=200)
```

> **Pitfall note for implementer:** The exact `StreamableHTTPServerTransport` API may vary between `mcp` SDK versions. Check `mcp.server.streamable_http` imports work with `pip show mcp` version. If the API differs (e.g. `handle_request` pattern instead of `run()`), adapt accordingly. The key contract is: authenticate → set user_id → delegate to MCP server → return response.

```python
"""stdio MCP server entry point.

Usage: Hermes config:
  mcp_servers:
    sift:
      command: "sift-mcp"
      env:
        SIFT_MCP_TOKEN: "sft_..."
        SIFT_DATABASE_URL: "postgresql+asyncpg://..."

Auth: SIFT_MCP_TOKEN env var (raw API token, validated against DB).
"""
import asyncio
import os
import sys

from mcp.server import Server
from mcp.server.stdio import stdio_server

from sift.mcp.tools import TOOL_DEFINITIONS, execute_tool
from sift.mcp.server import mcp_server
from sift.services.token_service import token_service
from sift.db.session import SessionLocal
from sift.db.models import User

from sqlalchemy import select


async def _resolve_user_from_env_token() -> User:
    raw_token = os.environ.get("SIFT_MCP_TOKEN")
    if not raw_token:
        print("SIFT_MCP_TOKEN environment variable not set", file=sys.stderr)
        sys.exit(1)

    async with SessionLocal() as session:
        token = await token_service.validate_token(session, raw_token)
        if token is None:
            print("Invalid or expired SIFT_MCP_TOKEN", file=sys.stderr)
            sys.exit(1)

        stmt = select(User).where(User.id == token.user_id)
        result = await session.execute(stmt)
        user = result.scalar_one_or_none()
        if user is None:
            print("Token user not found", file=sys.stderr)
            sys.exit(1)
        return user


async def main() -> None:
    user = await _resolve_user_from_env_token()

    # Patch the call_tool handler to use this user
    from sift.mcp.server import set_mcp_user_id
    set_mcp_user_id(user.id)

    async with stdio_server() as (read_stream, write_stream):
        await mcp_server.run(
            read_stream, write_stream,
            mcp_server.create_initialization_options(),
        )


def run() -> None:
    asyncio.run(main())


if __name__ == "__main__":
    run()
```

## Deferred Items

- **Frontend token management UI**: API tokens are managed via REST only; a settings panel for creating/revoking tokens is deferred until MCP is validated in production use.
- **MCP tool for OPML import**: Requires multipart file upload which doesn't map cleanly to MCP tool arguments; deferred until a URL-based or base64-encoded OPML import path exists.
- **MCP tool for feed discovery/recommendations**: Discovery endpoints are complex (multi-step generate → recommend → accept flow); deferred to a future iteration.
- **MCP sampling**: MCP server-to-client LLM requests (sampling) are not enabled; Sift doesn't need LLM completions from the MCP client.
- **WebSocket transport**: If low-latency real-time article notifications are needed, a WebSocket MCP transport could be added; deferred.
- **Scope enforcement**: API tokens have a `scopes_json` field but scope validation is not enforced in the MCP handler yet; all tokens get full access. Fine-grained scope enforcement is deferred until the scope model is designed.
